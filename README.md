# Mini CRM Project

A full-stack Mini Customer Relationship Management (CRM) application built using Node.js, Express, and HTML/CSS/JavaScript.

## Features
- **Add New Leads:** Form to submit candidate name, email, and phone number.
- **View All Leads:** Real-time dynamic dashboard displaying all leads.
- **Update Lead Status:** Change lead status to `Contacted` or `Closed`.
- **Delete Leads:** Remove unwanted leads instantly.
- **Database Support:** Connected with Express API endpoints and MongoDB database integration.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / Mongoose
